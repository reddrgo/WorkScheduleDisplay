# Work/Schedule Display

The Work/Schedule Display is a smart desktop productivity device inspired by the clean and simple interface of Spotify's "Now Playing" screen. Instead of displaying music information, it displays assignments, schedules, reminders, tasks, and upcoming events.
I decided to build this project because I often struggle to keep track of school assignments, engineering projects, and daily responsibilities. I wanted a dedicated display that could sit on my desk and show exactly what I need to work on without opening my phone or computer.
The display will be powered by an ESP32-S3 and a 2-inch TFT display. Users will be able to navigate tasks using buttons, mark tasks as completed, and view their daily progress. Future versions may include WiFi synchronization, voice commands, and integration with online task managers.
The enclosure is designed using foam board and CAD modeling to create a compact desktop device that is both functional and visually appealing.
