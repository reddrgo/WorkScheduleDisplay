# WorkScheduleDisplay
A smart productivity display built using an ESP32-S3 that shows schedules, assignments, and daily tasks in a modern Spotify-inspired interface.

## Features
- Daily task display
- Schedule tracking
- Check-off task system
- WiFi connectivity
- Compact Spotify-inspired UI

## Hardware
- ESP32-S3
- 2-inch TFT Display
- WiFi + BLE
- Cardboard enclosure

## Goals
Create a clean and functional desk display that helps students stay organized and productive.
